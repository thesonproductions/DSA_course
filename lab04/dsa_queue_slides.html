01 · Khái niệm

Hàng đợi (Queue) là gì?

Nguyên tắc FIFO

Phần tử vào trước được lấy ra trước (First In, First Out).

  • front: đầu hàng đợi, nơi lấy phần tử.
  • rear: cuối hàng đợi, nơi thêm phần tử.
  • enqueue() thêm ở rear; dequeue() lấy từ front.

05 · Array Queue

Queue biểu diễn bằng mảng

Những biến quan trọng

  • queue[]: dữ liệu trong mảng.
  • n: sức chứa tối đa.
  • front: chỉ số đầu hàng đợi.
  • count: số phần tử hiện có.
Có thể quản lý bằng cặp front / rear, hoặc front / count. Ta sử dụng cách thứ hai.
private Object[] queue;
private int n;
private int front = 0;
private int count = 0;

// Trạng thái Queue:
isEmpty = (count == 0);
isFull  = (count == n);

// Nếu chưa tính xoay vòng:
insertIndex = front + count;
06 · Vấn đề của Array Queue

Tại sao cách cài đặt tuyến tính chưa ổn?

public void enqueue(E x) {
    if (count < n) {
        queue[front + count] = x;
        count++;
    }
}

public E dequeue() {
    if (count > 0) {
        count--;
        return queue[front++];
    }
    return null;
}

Lỗ hổng chỉ số

count < n không đảm bảo front + count < n.

Sau khi dequeue, ô đầu mảng trở nên trống nhưng front tăng dần. Nếu enqueue tiếp, ta có thể ghi vượt giới hạn mảng.

08 · Circular Queue

Giải pháp: mảng vòng dùng toán tử %

Ý tưởng

Khi đi đến cuối mảng, chỉ số quay lại đầu mảng để tái sử dụng ô trống.

(front + count) % n

  • Thêm phần tử: ghi vào ô tiếp theo.
  • Xoá phần tử: tăng front rồi lấy modulo.
  • Không cần dịch mảng.

10 · Java implementation

Mã Java: enqueue() với modulo

public void enqueue(E element) {
    if (count == n) {
        throw new
            IllegalStateException(
                "Queue is full");
    }
    int i = (front + count) % n;
    queue[i] = element;
    count++;
}

Giải thích

  1. Nếu count == n, Queue đã đầy.
  2. Tính ô ghi bằng phép modulo.
  3. Gán phần tử vào vị trí này.
  4. Tăng count sau khi thêm.

Thời gian O(1)

Tài liệu gốc im lặng khi mảng đầy; bản lab sử dụng exception để phát hiện lỗi rõ ràng.
11 · Java implementation

Mã Java: dequeue() và front()

public E dequeue() {
    if (count == 0) {
        throw new
          NoSuchElementException();
    }
    E x = (E) queue[front];
    queue[front] = null;
    front = (front + 1) % n;
    count--;
    return x;
}
public E front() {
    if (count == 0) {
        throw new
          NoSuchElementException();
    }
    return (E) queue[front];
}

public boolean isEmpty() {
    return count == 0;
}

Gán null vào ô đã lấy nhằm giải phóng tham chiếu. Các hàm xử lý underflow tường minh.

12 · Circular Queue invariants

Rỗng, đầy và thứ tự logic

Các điều kiện

  • count == 0: rỗng.
  • count == n: đầy.
  • 0 ≤ front < n.
  • Phần tử logic thứ i ở (front+i)%n.
Không dịch phần tử

Ví dụ front = 3, count = 3, n = 5

i logicVị trí vật lý
0(3+0)%5 = 3
1(3+1)%5 = 4
2(3+2)%5 = 0

Không được nhầm thứ tự 0→4 trong mảng với thứ tự FIFO.

15 · Linked-list Java

Mã Java: thêm vào cuối danh sách

private class Node {
    E element;
    Node next;
}
private Node head = null;
private Node rear = null;

public void enqueue(E x) {
    Node node = new Node();
    node.element = x;
    if (rear != null)
        rear.next = node;
    else
        head = node;
    rear = node;
}

Hai tình huống

Queue đã có phần tử: nối node mới vào rear.next.

Queue rỗng: node mới là cả head lẫn rear.

Khác Stack với linked list: enqueue không thêm ở đầu.
16 · Linked-list Java

Mã Java: lấy đầu danh sách

public E dequeue() {
    if (head == null)
        throw new
          NoSuchElementException();

    E x = head.element;
    head = head.next;
    if (head == null)
        rear = null;
    return x;
}

Lưu ý trường hợp biên

  1. Chỉ có một node, head == rear.
  2. dequeue làm head = null.
  3. Bắt buộc gán rear = null.
Tránh con trỏ rear bị treo
