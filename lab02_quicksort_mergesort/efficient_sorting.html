Phần I · Merge Sort

Merge Sort: “chia nhỏ rồi ghép lại”

Ý tưởng cốt lõi

  1. Divide: chia mảng thành hai nửa.
  2. Conquer: sắp xếp đệ quy từng nửa.
  3. Combine: trộn hai nửa đã có thứ tự.

Một chút lịch sử

John von Neumann đề xuất Merge Sort vào năm 1945, trong những ngày đầu của máy tính điện tử.

Điểm đặc biệt: hiệu năng O(n log n) được bảo đảm ngay cả trong trường hợp xấu.

03 · Merge Sort
Merge Sort · pseudo-code

Tách trách nhiệm: sort và merge

MERGE_SORT(A):
  if len(A) ≤ 1:
    return A

  mid = len(A) // 2
  left  = MERGE_SORT(A[:mid])
  right = MERGE_SORT(A[mid:])

  return MERGE(left, right)
MERGE(L, R):
  result = []
  while L and R:
    take smaller front item
    append it to result

  append remaining items
  return result
03 · Merge Sort
Merge Sort · Java

Triển khai bằng Java

static void mergeSort(int[] a, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(a, left, mid);
    mergeSort(a, mid + 1, right);
    merge(a, left, mid, right);
}

static void merge(int[] a, int left, int mid, int right) {
    int[] temp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;
    while (i <= mid && j <= right)
        temp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= mid) temp[k++] = a[i++];
    while (j <= right) temp[k++] = a[j++];
    for (int t = 0; t < temp.length; t++) a[left + t] = temp[t];
}

Merge Sort · Complexity

Vì sao là O(n log n)?

Thời gian

O(n log n)

Best = Average = Worst

Bộ nhớ phụ

O(n)

Cho các mảng tạm khi merge.

Tính chất

Stable ✓

Giữ thứ tự tương đối của phần tử bằng nhau nếu merge đúng.

Trực giác: có khoảng log₂n tầng, mỗi tầng xử lý tổng cộng n phần tử.

Quick Sort: “đặt pivot đúng chỗ”

Ý tưởng cốt lõi

  1. Chọn một pivot.
  2. Partition: đưa phần tử nhỏ hơn pivot sang trái, lớn hơn sang phải.
  3. Đệ quy trên hai phía.

Một chút lịch sử

Tony Hoare phát minh Quick Sort năm 1959 và công bố năm 1961.

Quick Sort nổi tiếng vì chạy rất nhanh trong thực tế và có thể sắp xếp in-place.

09 · Quick Sort
Quick Sort · pseudo-code

Bản Lomuto partition — dễ học và dễ code

QUICK_SORT(A, low, high):
  if low < high:
    p = PARTITION(A, low, high)
    QUICK_SORT(A, low, p - 1)
    QUICK_SORT(A, p + 1, high)
PARTITION(A, low, high):
  pivot = A[high]
  i = low

  for j = low .. high - 1:
    if A[j] <= pivot:
      swap A[i], A[j]
      i += 1

  swap A[i], A[high]
  return i
09 · Quick Sort
Quick Sort · Java

Triển khai Lomuto partition bằng Java

static void quickSort(int[] a, int low, int high) {
    if (low >= high) return;
    int p = partition(a, low, high);
    quickSort(a, low, p - 1);
    quickSort(a, p + 1, high);
}

static int partition(int[] a, int low, int high) {
    int pivot = a[high], i = low;
    for (int j = low; j < high; j++) {
        if (a[j] <= pivot) {
            int tmp = a[i]; a[i] = a[j]; a[j] = tmp;
            i++;
        }
    }
    int tmp = a[i]; a[i] = a[high]; a[high] = tmp;
    return i;
}
11 · Quick Sort
Quick Sort · Complexity

Rất nhanh trung bình, nhưng có worst-case

Best / Average

O(n log n)

Pivot chia khá cân bằng.

Worst

O(n²)

Pivot liên tục rơi vào cực trị.

Bộ nhớ

O(log n)*

Stack đệ quy trung bình; worst có thể O(n).

Giảm rủi ro: random pivot, median-of-three, hoặc giới hạn recursion depth trong triển khai thực tế.

Chọn thuật toán

Khi nào dùng cái nào?

Ưu tiên Merge Sort khi…

  • Cần stable sort.
  • Cần worst-case O(n log n).
  • Dữ liệu lớn / external sorting.
  • Linked list — merge rất tự nhiên.

Ưu tiên Quick Sort khi…

  • Sắp xếp array trong RAM.
  • Muốn in-place và cache locality tốt.
  • Chọn pivot tốt / random hóa.
  • Hiệu năng thực tế quan trọng.
