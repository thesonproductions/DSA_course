Array Stack

Cài đặt Stack bằng mảng

Ý tưởng

  • Dùng mảng elements[] để lưu phần tử.
  • Biến top trỏ tới vị trí đỉnh stack.
  • Thêm/xoá ở cuối vùng đang dùng của mảng.
  • Khi mảng đầy, có thể mở rộng mảng.

push O(1) pop O(1) có giới hạn capacity

public class SimpleArrayStack<T>
        implements SimpleStack<T> {

    private Object[] elements;
    private int top = -1;
    private int size = 0;

    public SimpleArrayStack(int capacity) {
        elements = new Object[capacity];
    }
}
04 · Array implementationtop = -1 nghĩa là stack rỗng
Array Stack · Java-like pseudocode

Mã giả Java: push, pop, size

public void push(T item) {
    if (size == elements.length) {
        enlarge();
    }

    top = top + 1;
    elements[top] = item;
    size = size + 1;
}
public T pop() {
    if (isEmpty()) {
        throw new RuntimeException("Stack empty");
    }

    T item = (T) elements[top];
    elements[top] = null;
    top = top - 1;
    size = size - 1;
    return item;
}
public int size() { return size; }
public boolean isEmpty() { return size == 0; }

Dynamic Array

Mở rộng mảng bằng Repeated Doubling

06 · Dynamic arrayKhi đầy: cấp phát mảng mới gấp đôi, copy dữ liệu sang
Dynamic Array · Java-like pseudocode

Hàm enlarge(): tạo mảng mới rồi copy

private void enlarge() {
    int newCapacity = elements.length * 2;
    Object[] newElements = new Object[newCapacity];

    for (int i = 0; i < size; i++) {
        newElements[i] = elements[i];
    }

    elements = newElements;
}

Ghi nhớ

  • Không nên tăng capacity từng ô một.
  • Tăng gấp đôi giúp giảm số lần copy.
  • Một lần enlarge tốn O(n), nhưng trung bình mỗi push vẫn hiệu quả.

Linked-list Stack

Cài đặt Stack bằng danh sách liên kết đơn

Ý tưởng

  • Mỗi phần tử là một Node.
  • top là node đầu của danh sách.
  • push: thêm node mới vào đầu danh sách.
  • pop: lấy node đầu và chuyển top sang node kế tiếp.

không cần capacity cố định dùng con trỏ next

private class Node {
    T data;
    Node next;

    Node(T data, Node next) {
        this.data = data;
        this.next = next;
    }
}

private Node top = null;
private int size = 0;

09 · Linked-list Stackpush: node.next = top; top = node
Linked-list Stack · Java-like pseudocode

Mã giả Java: thêm và xoá ở đầu danh sách

public void push(T item) {
    Node node = new Node(item, top);
    top = node;
    size++;
}
public T pop() {
    if (isEmpty()) {
        throw new RuntimeException("Stack empty");
    }

    T item = top.data;
    top = top.next;
    size--;
    return item;
}
public int size() { return size; }
public boolean isEmpty() { return top == null; }

12 · Balanced parenthesesGặp '(' thì push, gặp ')' thì pop
Ứng dụng 1 · Java-like pseudocode

Mã giả Java: kiểm tra ngoặc

public static boolean isBalanced(String expr) {
    SimpleStack<Character> stack = new SimpleArrayStack<>();

    for (int i = 0; i < expr.length(); i++) {
        char c = expr.charAt(i);

        if (c == '(') stack.push(c);

        if (c == ')') {
            if (stack.isEmpty()) return false;
            stack.pop();
        }
    }

    return stack.isEmpty();
}

Logic kiểm tra

  1. Dấu mở (: chờ một dấu đóng tương ứng.
  2. Dấu đóng ): phải có dấu mở trước đó.
  3. Duyệt xong: stack phải rỗng.

true nếu mọi dấu mở đều được đóng đúng.

14 · Postfix evaluationGặp số: push · gặp toán tử: pop 2 toán hạng rồi push kết quả
Ứng dụng 2 · Java-like pseudocode

Mã giả Java: tính biểu thức hậu tố

public static int evalPostfix(String expr) {
    SimpleStack<Integer> stack = new SimpleLinkedStack<>();

    for (String token : expr.split(" ")) {
        if (token.matches("-?\\d+")) {
            stack.push(Integer.parseInt(token));
        } else {
            int b = stack.pop();
            int a = stack.pop();
            stack.push(apply(a, b, token));
        }
    }
    return stack.pop();
}
private static int apply(int a, int b, String op) {
    switch (op) {
        case "+": return a + b;
        case "-": return a - b;
        case "*": return a * b;
        case "/": return a / b;
        default: throw new RuntimeException("Bad op");
    }
}
